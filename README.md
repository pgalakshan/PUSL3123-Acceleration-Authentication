# PUSL3123 Acceleration-Based User Authentication

Independent coursework implementation for the PUSL3123 AI and Machine Learning module.

## Objective

This project investigates acceleration-based behavioural authentication using supervised machine learning in MATLAB.

The work includes:

- dataset quality analysis
- descriptive statistics
- inter-user and intra-user variance analysis
- feature-domain comparison
- dimensionality analysis
- supervised authentication modelling
- parameter optimisation
- feature selection
- cross-day evaluation
- performance analysis using biometric authentication metrics

## Dataset

The supplied dataset contains acceleration-based features for 10 users.

Feature domains:

- Frequency domain: 43 features
- Time domain: 88 features
- Combined time and frequency domain: 131 features

Each user contains FDay and MDay feature matrices with 36 samples per day.
